# سیستم مدیریت دبیرستان شایستگان

سیستم وب کامل برای مدیریت مالی و آموزشی **دبیرستان غیرانتفاعی شایستگان**.

## امکانات

### مدیریت آموزشی
- **کلاس‌ها**: تعریف کلاس با پایه، رشته، شهریه و ظرفیت
- **دانش‌آموزان**: ثبت دانش‌آموز و انتساب به کلاس
- **معلمان**: اطلاعات تماس و حساب بانکی
- **دروس و حق‌التدریس**: تعریف درس + نرخ ساعتی (هر ساعت = ۴۵ دقیقه)
- **برنامه کلاسی**: روز، ساعت شروع و پایان، کلاس، درس، معلم
- **حضور معلمان**: ثبت حضور طبق برنامه → محاسبه خودکار ساعت تدریس و مبلغ
- **حضور دانش‌آموزان**: لیست دانش‌آموزان هر کلاس

### مدیریت مالی
- **درآمدها**: ثبت شهریه و سایر درآمدها
- **هزینه‌ها**: ثبت هزینه‌های مدرسه (اجاره، آب و برق، ...)
- **پرداخت معلمان**: 
  - محاسبه خودکار: مجموع ساعات حضور × نرخ درس
  - کسر مساعده و سایر کسورات
  - مبلغ نهایی قابل پرداخت به هر معلم

### منطق محاسبه ساعت تدریس
هر جلسه بر اساس `ساعت پایان - ساعت شروع` محاسبه می‌شود و تقسیم بر ۴۵ دقیقه می‌شود.  
مثال: ۸:۰۰ تا ۹:۳۰ = ۹۰ دقیقه = **۲ ساعت تدریس**.

## نصب و اجرا

### پیش‌نیاز
- Node.js 18 یا بالاتر
- npm

### مراحل

```bash
# کلون کردن
git clone https://github.com/kohanpour1/shayestegan-school-management.git
cd shayestegan-school-management

# نصب وابستگی‌ها
npm install

# ایجاد دیتابیس و جداول
npx prisma db push

# اجرای محیط توسعه
npm run dev
```

سپس مرورگر را باز کنید: [http://localhost:3000](http://localhost:3000)

### دیتابیس
از SQLite استفاده شده (فایل `prisma/dev.db`). برای تولید می‌توانید به PostgreSQL تغییر دهید.

### دستورات مفید
```bash
npm run db:studio   # مشاهده و ویرایش داده‌ها با Prisma Studio
npm run build       # ساخت نسخه production
npm start           # اجرای نسخه production
```

## ساختار پروژه
- `src/app` — صفحات و API Routes (Next.js App Router)
- `src/components` — فرم‌ها و کامپوننت‌های کلاینت
- `src/lib` — Prisma client و توابع کمکی (محاسبه ساعت، فرمت پول)
- `prisma/schema.prisma` — مدل‌های دیتابیس

## تکنولوژی
- Next.js 14 + TypeScript
- Prisma + SQLite
- Tailwind CSS
- پشتیبانی کامل از RTL و فونت وزیرمتن
